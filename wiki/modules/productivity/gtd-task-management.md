# GTD: Task Management & Cognitive Load Reduction

> **Source:** [[raw-sources/productivity-and-system]] (section 4), David Allen — *Getting Things Done*.

Externalize every open loop so the mind is free to think instead of remember. The mind is for having ideas, not holding them.

---

## 1. Core Principle

Everything unfinished or undecided occupies cognitive RAM. Offload all tasks into a **trusted external system** to reduce mental friction and free working memory for the work itself.

---

## 2. The 5 Workflow Stages

1. **Capture** — Collect everything into an inbox (no judging while collecting).
2. **Clarify** — Is it actionable?
   - If it *can* be done in under 2 minutes → **do it immediately**.
   - Otherwise → **delegate** it or **defer** it.
3. **Organize** — Route outcomes into **Next Actions**, **Waiting For**, or **Scheduled** calendar events.
4. **Reflect** — Perform a **Weekly Review** to clean and sync all systems (catch-all for drift).
5. **Engage** — Execute based on **context**, **time available**, and **energy level**.

---

## 3. How GTD Complements the Other Systems

- GTD **Capture** is task-level; [[pkm-code-framework]] **Capture** is idea-level. Both feed the same inbox discipline.
- The 2-minute rule is GTD's version of friction reduction — the same instinct as habit-building's 2-Minute Rule in [[atomic-habits-systems]].
- **Reflect (Weekly Review)** ≈ the "Cadence of Accountability" from [[deep-work-attention-economics]] and the "Needs reflection" check of Progressive Summarization.
- **Engage** by context/time/energy decides *when* deep blocks get scheduled ([[deep-work-attention-economics]]) and which Eisenhower cell a task belongs to ([[mental-models-for-execution]]).
