# Inorganic Chemistry Trends & Exceptions — Quick Reference

> High-yield trends, anomalies, and exceptions for JEE Advanced. Memorize the "violations" — they're frequently tested.

---

## 📐 Periodic Trends Summary

| Property | Across Period (L→R) | Down Group | Reason |
|----------|---------------------|------------|--------|
| Atomic Radius | ↓ Decreases | ↑ Increases | $Z_{eff}$ ↑; new shell added |
| Ionic Radius | ↓ (isoelectronic) | ↑ | $Z_{eff}$ ↑; new shell |
| Ionization Energy | ↑ Increases | ↓ Decreases | $Z_{eff}$ ↑; distance ↑, shielding ↑ |
| Electron Affinity | ↑ (generally) | ↓ (generally) | $Z_{eff}$ ↑; size ↑ |
| Electronegativity | ↑ Increases | ↓ Decreases | $Z_{eff}$ ↑; distance ↑ |
| Metallic Character | ↓ Decreases | ↑ Increases | IE ↓, EA ↓ |
| Acidic Oxide | ↑ Increases | - | Non-metallic character ↑ |
| Basic Oxide | ↓ Decreases | - | Metallic character ↓ |

## 🔴 Major Anomalies (Memorize These!)

### Diagonal Relationships
| Pair | Similarities |
|------|--------------|
| **Li–Mg** | Hard, high mp/bp, form nitrides, carbonates decompose on heating, hydroxides sparingly soluble |
| **Be–Al** | Amphoteric oxides/hydroxides, form $BeF_4^{2-}/AlF_6^{3-}$, covalent chlorides, form carbides |
| **B–Si** | Semiconductors, form covalent network solids, acidic oxides, form halides hydrolyzed by water |

### Group 1 (Alkali Metals) — Li Anomalies
| Property | Li | Others (Na, K, Rb, Cs) |
|----------|-----|------------------------|
| Hardness | Hard | Soft |
| Melting Point | High (180°C) | Low |
| Nitride Formation | $6Li + N_2 \to 2Li_3N$ | Don't form directly |
| Carbonate Stability | $Li_2CO_3 \xrightarrow{\Delta} Li_2O + CO_2$ | Stable (except $Li$) |
| Hydroxide Solubility | Sparingly soluble | Highly soluble |
| Hydration | $Li^+$ heavily hydrated | Less hydrated |
| Ionic Mobility | Lowest (high hydration) | Higher |

### Group 2 (Alkaline Earth) — Be Anomalies
| Property | Be | Others (Mg, Ca, Sr, Ba, Ra) |
|----------|-----|----------------------------|
| Hardness | Hard | Soft |
| M.P./B.P. | High | Lower |
| Oxidation State | Only +2 | +2 (mainly) |
| Coordination No. | 4 (tetrahedral) | 6 (octahedral) |
| Oxide/Hydroxide | **Amphoteric** | Basic |
| Chloride | Covalent, $BeCl_2$ (polymeric) | Ionic |
| Complexes | Forms $BeF_4^{2-}$, $Be(OH)_4^{2-}$ | Few complexes |
| Carbide | $Be_2C$ (methanide) | $CaC_2$ (acetylide) |
| Fajan's Rules | High polarizing power | Lower |

### Group 13 (Boron Family) — B Anomalies
| Property | B | Others (Al, Ga, In, Tl) |
|----------|-----|------------------------|
| Nature | Non-metal | Metals |
| Allotropy | Amorphous, crystalline | No |
| Max Covalency | 4 (no d-orbitals) | 6 (d-orbitals) |
| Oxide | Acidic ($B_2O_3$) | Amphoteric ($Al_2O_3$) / Basic |
| $BF_3$ | Strong Lewis acid | - |
| Hydride | $B_2H_6$ (electron deficient, 3c-2e bonds) | $AlH_3$ (polymeric) |
| $BCl_3$ Hydrolysis | $BCl_3 + 3H_2O \to B(OH)_3 + 3HCl$ | $AlCl_3$ hydrolyzes violently |

### Group 14 (Carbon Family) — C Anomalies
| Property | C | Others (Si, Ge, Sn, Pb) |
|----------|---|------------------------|
| Catenation | Maximum ($C-C$ strong) | Decreases down group |
| Allotropy | Diamond, Graphite, Fullerenes, Graphene | Few (Si, Ge) |
| Multiple Bonds | $C=C, C≡C$ common | Rare (π bonds weak) |
| Max Oxidation | +4 | +4, +2 (inert pair effect ↑) |
| $CO_2$ | Gas, linear | $SiO_2$ solid (network) |
| Halides | $CCl_4$ (covalent, non-hydrolyzed) | Hydrolyzed readily |

### Group 15 (Nitrogen Family) — N Anomalies
| Property | N | Others (P, As, Sb, Bi) |
|----------|---|------------------------|
| State | Diatomic gas ($N_2$) | Solids |
| Allotropy | None | Multiple (white/red P, etc.) |
| Multiple Bonds | $N≡N, C≡N, N=O$ common | Rare |
| H-Bonding | Strong ($NH_3, H_2O$) | Weak |
| Oxidation States | -3 to +5 | -3 to +5 (+3 stable for Bi) |
| $N_2$ Inertness | Very high (triple bond) | - |
| Basicity | $NH_3$ > $PH_3$ > $AsH_3$ | Decreases |
| Catenation | Weak ($N-N$ weak) | Stronger ($P-P$) |

### Group 16 (Oxygen Family) — O Anomalies
| Property | O | Others (S, Se, Te, Po) |
|----------|---|------------------------|
| State | Diatomic gas ($O_2$) | Solids |
| Allotropy | $O_2, O_3$ (ozone) | Multiple (S: rhombic, monoclinic, plastic) |
| Oxidation State | -2 (mostly), -1 ($H_2O_2$), +2 ($OF_2$) | -2 to +6 |
| H-Bonding | Very strong | Weak |
| Catenation | $H_2O_2, O_3$ | Strong ($S_8, S_n^{2-}$) |
| Paramagnetism | $O_2$ paramagnetic | Diamagnetic |
| Oxidizing Power | Strongest | Decreases down |

### Group 17 (Halogens) — F Anomalies
| Property | F | Others (Cl, Br, I, At) |
|----------|---|------------------------|
| Electronegativity | Highest (4.0) | Decreases |
| Oxidation State | Only -1 | -1, +1, +3, +5, +7 |
| H-Bonding | Strongest ($HF$) | Weaker |
| $HF$ | Weak acid ($pK_a=3.2$) | Strong acids ($HCl, HBr, HI$) |
| $F_2$ Reactivity | Most reactive | Decreases |
| Interhalogens | $IF_7$ exists (max coordination) | $ClF_5, BrF_5, IF_5$ |
| Oxidizing Power | Strongest ($E^\circ = +2.87$ V) | Decreases |

### Group 18 (Noble Gases) — He Anomalies
| Property | He | Others (Ne, Ar, Kr, Xe, Rn) |
|----------|---|------------------------|
| Electron Config | $1s^2$ | $ns^2 np^6$ |
| Compounds | None (no stable compounds) | $XeF_2, XeF_4, XeF_6, XeO_3, KrF_2$ |
| Liquefaction | Most difficult (lowest b.p. 4.2 K) | Easier down group |

## 🔴 f-Block (Lanthanides/Actinides)

### Lanthanide Contraction
- Steady decrease in atomic/ionic radii from La to Lu
- Cause: Poor shielding of $4f$ electrons
- Consequence: $Zr \approx Hf$, $Nb \approx Ta$, $Mo \approx W$ (size, properties)

### Common Oxidation States
| Element | States | Most Stable |
|---------|--------|-------------|
| **La** | +3 | +3 |
| **Ce** | +3, +4 | +3 (+4 oxidizing) |
| **Pr** | +3, +4 | +3 |
| **Nd** | +2, +3, +4 | +3 |
| **Pm** | +3 | +3 |
| **Sm** | +2, +3 | +3 (+2 reducing) |
| **Eu** | +2, +3 | +3 (+2 stable, $f^7$) |
| **Gd** | +3 | +3 |
| **Tb** | +3, +4 | +3 (+4 oxidizing) |
| **Dy** | +3, +4 | +3 |
| **Ho** | +3 | +3 |
| **Er** | +3 | +3 |
| **Tm** | +2, +3 | +3 |
| **Yb** | +2, +3 | +3 (+2 stable, $f^{14}$) |
| **Lu** | +3 | +3 |

### Actinides
- All radioactive; Th, Pa, U naturally occurring
- Oxidation states up to +7 (Np, Pu)
- $U$: +3, +4, +5, +6 (most common +4, +6 as $UO_2^{2+}$)

## 🔴 Coordination Compounds — Exceptions

### Geometrical Isomerism Exceptions
| Complex | Geometry | Isomers |
|---------|----------|---------|
| $MA_2B_2$ | Square planar | cis, trans |
| $MA_2B_2$ | Tetrahedral | **None** |
| $MA_3B_3$ | Octahedral | fac, mer |
| $M(AA)_2B_2$ | Octahedral | cis ($\Delta, \Lambda$), trans |
| $M(AA)_3$ | Octahedral | $\Delta, \Lambda$ (optical) |

### Magnetic Moment Exceptions (Spin-Orbit Coupling)
- $Fe^{2+}$ (HS): $\mu_{exp} \approx 5.1-5.5$ BM (not 4.90)
- $Co^{2+}$ (HS): $\mu_{exp} \approx 4.7-5.2$ BM (not 3.87)
- $Ni^{2+}$: $\mu_{exp} \approx 3.2-3.5$ BM (not 2.83)
- **Reason:** Orbital angular momentum contribution

### Thermodynamic Stability
- **Irving-Williams Series:** $Mn^{2+} < Fe^{2+} < Co^{2+} < Ni^{2+} < Cu^{2+} > Zn^{2+}$
- **Chelate Effect:** $M + 4L \rightleftharpoons ML_4$ vs $M + 2(AA) \rightleftharpoons M(AA)_2$; chelate more stable
- **Macrocyclic Effect:** Cyclic multidentate > open-chain chelate

## 🔴 Qualitative Analysis — Key Separations

### Cation Groups (Classic Scheme)
| Group | Reagent | Precipitates as | Members |
|-------|---------|-----------------|---------|
| **I** | $HCl$ (dil.) | Chlorides | $Ag^+, Pb^{2+}, Hg_2^{2+}$ |
| **II** | $H_2S$ (acidic, $0.3M HCl$) | Sulphides | $Pb^{2+}, Cu^{2+}, Cd^{2+}, Bi^{3+}, Hg^{2+}, As^{3+}, Sb^{3+}, Sn^{2+}$ |
| **III** | $H_2S$ (basic, $NH_4Cl + NH_4OH$) | Hydroxides | $Fe^{3+}, Al^{3+}, Cr^{3+}$ |
| **IV** | $H_2S$ (basic, $NH_4Cl + NH_4OH$) | Sulphides | $Co^{2+}, Ni^{2+}, Mn^{2+}, Zn^{2+}$ |
| **V** | $(NH_4)_2CO_3$ (basic) | Carbonates | $Ba^{2+}, Sr^{2+}, Ca^{2+}$ |
| **0** | - | In solution | $NH_4^+, Mg^{2+}, K^+, Na^+$ |

### Anion Tests (Confirmatory)
| Anion | Test | Observation |
|-------|------|-------------|
| $CO_3^{2-}$ | $H_2SO_4$ | $CO_2$ effervescence, lime water milky |
| $S^{2-}$ | $H_2SO_4$ | $H_2S$ gas (rotten egg), lead acetate black |
| $SO_3^{2-}$ | $H_2SO_4$ | $SO_2$ gas (burning sulfur smell), $KMnO_4$ decolorizes |
| $NO_2^-$ | $H_2SO_4 + FeSO_4$ | Brown ring ($[Fe(NO)]^{2+}$) |
| $NO_3^-$ | $FeSO_4 + H_2SO_4$ (conc.) | Brown ring |
| $Cl^-$ | $AgNO_3$ | White ppt ($AgCl$), soluble in $NH_3$ |
| $Br^-$ | $AgNO_3$ | Pale yellow ppt ($AgBr$), sparingly soluble in $NH_3$ |
| $I^-$ | $AgNO_3$ | Yellow ppt ($AgI$), insoluble in $NH_3$ |
| $PO_4^{3-}$ | $(NH_4)_2MoO_4 + HNO_3$ | Yellow ppt ($NH_4)_3[PMo_{12}O_{40}]$) |
| $BO_3^{3-}$ | $H_2SO_4 + C_2H_5OH$ | Green flame (ethyl borate) |

### Interfering Radicals & Removal
| Interfering | Removed By |
|-------------|------------|
| $PO_4^{3-}, AsO_4^{3-}$ | $MgCO_3$ or $Mg(NO_3)_2$ before Group II |
| $BO_3^{3-}, F^-$ | Evaporate with $H_2SO_4$ before Group II |
| $CrO_4^{2-}$ | Reduce with $SO_2$ or $H_2S$ |
