# PKM: The CODE Framework & PARA Method

> **Source:** [[raw-sources/productivity-and-system]] (section 2), Tiago Forte — *Building a Second Brain*.

A personal knowledge management (PKM) workflow that turns raw stimuli into a reusable, searchable body of work — and this wiki itself is an instance of it.

---

## 1. The CODE Framework

1. **Capture** — Collect resonant information. Keep it **high-signal, low-friction**: capture quickly, judgment-free, only what resonates.
2. **Organize** — Structure by **actionability**, not by topic, using **PARA** (see below). This is the key: organization serves action.
3. **Distill** — Extract core insights through **Progressive Summarization**: bold main points → highlight key sentences → summarize into executive bullet points. Layer by layer so notes stay scannable.
4. **Express** — Output tangible work using **intermediate packets** — notes, code blocks, frameworks — assembled into larger deliverables.

---

## 2. The PARA Method

| Category | Definition | Examples |
|---|---|---|
| **Projects** | Short-term efforts with a deadline and a specific deliverable | A thesis, a build, a module write-up |
| **Areas** | Ongoing responsibilities maintained over time | Health, Learning, Finance |
| **Resources** | Topics of ongoing interest / reference material | Interesting articles, tool references |
| **Archives** | Inactive items from the other three categories | Completed or abandoned projects |

> Rule of thumb: if something is not actionable or a standing responsibility, it is a **Resource**. If it is stale, it is an **Archive**.

---

## 3. The CODE Loop Applied to This Wiki

- **Capture**: `/raw-sources/*.md` + extracted PDFs are the high-signal inbox.
- **Organize**: `/wiki/` nodes carry YAML frontmatter (`module`, `topic`, `tags`) — organized by actionability/research track, mirroring PARA.
- **Distill**: Each module page's one-line precis tables and "Key Concepts" sections *are* progressive summarization.
- **Express**: Intermediate packets (derivations, C++/Python blocks) become the study deliverables in [[learning-roadmap-and-study-plan]].
