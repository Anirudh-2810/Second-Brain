# German Alphabet & Pronunciation

> German is **phonetic** — words are almost always pronounced as written, once you know the rules. Learn the sounds first and everything else gets easier.

---

## The alphabet (26 + 4 special letters)

The 26 English letters, plus **ä, ö, ü** (Umlaute) and **ß** (Eszett / sharp s).

| Letter | Say it like | Letter | Say it like |
|---|---|---|---|
| A a | "ah" (father) | N n | "en" |
| B b | "beh" | O o | "oh" |
| C c | "tseh" | P p | "peh" |
| D d | "deh" | Q q | "koo" |
| E e | "eh" (bet) | R r | "err" (rolled) |
| F f | "eff" | S s | "ess" |
| G g | "geh" | T t | "teh" |
| H h | "hah" | U u | "oo" (moon) |
| I i | "ee" (see) | V v | "fau" |
| J j | "yott" | W w | "veh" |
| K k | "kah" | X x | "iks" |
| L l | "ell" | Y y | "uepsilon" |
| M m | "emm" | Z z | "tsett" |

**The extra 4:**

| Letter | Sound (approx.) | English clue |
|---|---|---|
| **ä** | "eh" | like **e** in "bet", lips spread |
| **ö** | "er" | say "er" (her) with **rounded** lips |
| **ü** | "ü" | say "ee" (see) with **rounded** lips |
| **ß** | "ss" | sharp s, like in "hiss" |

> **Trick for ö/ü:** German speakers say *"I don't care"* for ö (sounds like "er") and *"eww"* for ü. Practise in a mirror — the lips round forward.

## Core sound rules (memorize these)

| German | Sounds like | Example |
|---|---|---|
| **sch** | "sh" | Schule (school) |
| **tsch** | "ch" (church) | Deutsch (German) |
| **z** | "ts" | Zeit (time) |
| **v** | "f" | Vogel (bird) |
| **w** | "v" | Wasser (water) |
| **j** | "y" | ja (yes) |
| **qu** | "kv" | Qualität |
| **ei** | "eye" | nein (no) |
| **ie** | "ee" (long) | Liebe (love) |
| **au** | "ow" | Haus (house) |
| **eu / äu** | "oy" | neu (new) |
| **ch (after a, o, u)** | guttural "ch" (Scottish *loch*) | Buch, Nacht |
| **ch (after e, i, ä, ö, ü, consonants)** | soft "ich" (whisper *sh*) | ich, Milch |
| **st / sp (word start)** | "sht" / "shp" | Stadt, Sprache |
| **h after vowel** | lengthens vowel, h silent | gehen (gay-en) |
| **-er (end)** | "ah" (weak) | Wasser → "Vass-ah" |
| **-ig (end)** | "ich" | richtig → "richt-ich" |

## Vowels: long vs short

- **Long vowel** = say it stretched (marked by double vowel, h after vowel, or single vowel + one consonant then vowel).
- **Short vowel** = say it snappy (before double consonants like **nn, tt, ss**).

| Long | Short |
|---|---|
| **a** — Tag (tahk) | **a** — Mann (mon) |
| **e** — Weg (veyk) | **e** — Bett (bet) |
| **i** — Liebe (lee-be) | **i** — bitte (bit-te) |
| **o** — Sohn (zohn) | **o** — kommen (kom-men) |
| **u** — gut (goot) | **u** — Mutter (moot-ter) |

**Double consonants always make the vowel SHORT:** kommen, bitte, besser.

---

## Stress (where to put emphasis)

- Usually on the **first syllable** of the word: **Ar**beit, **Win**ter, **Leh**rer.
- Verb prefixes (be-, ge-, er-, ver-, zer-, ent-) are **unstressed**: be**kom**men, ge**hen**.
- Separable prefixes (auf-, an-, aus-, mit-) carry stress: **auf**stehen, **mit**kommen.

---

## 3 pronunciation traps (avoid these!)

1. **V ≠ W.** German **w** = English **v** (Wasser = "Vass-er"); German **v** = English **f** (Vogel = "Foh-gel").
2. **Z = "ts",** never "z" — Zeit = "Tsite".
3. **ich ≠ "ick".** The soft **ch** is a breathy "sh"; never say a hard "k" (that's only in words like *auch*).
