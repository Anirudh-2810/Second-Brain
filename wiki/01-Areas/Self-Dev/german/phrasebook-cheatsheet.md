# German A1 — Phrasebook Cheat Sheet

> One-page survival phrasebook. Print it, screenshot it, pin it. All the phrases you actually need at A1.

---

## Essentials

| German | English |
|---|---|
| Hallo! / Guten Tag! | Hello! / Good day! |
| Guten Morgen / Abend! | Good morning / evening! |
| Tschüss! / Auf Wiedersehen! | Bye! |
| Danke (schön)! | Thanks (very much)! |
| Bitte! | Please / You're welcome! |
| Entschuldigung! | Excuse me / Sorry! |
| Ja / Nein | Yes / No |
| Ich verstehe (nicht). | I (don't) understand. |
| Sprechen Sie Englisch? | Do you speak English? |
| Ich spreche nur ein bisschen Deutsch. | I only speak a little German. |
| Können Sie das bitte wiederholen? | Could you repeat that, please? |
| Langsamer, bitte. | Slower, please. |
| Wie sagt man das auf Deutsch? | How do you say that in German? |

## Questions (the W-words)

| Word | Use | Example |
|---|---|---|
| **Wer?** | who | Wer ist das? |
| **Was?** | what | Was kostet das? |
| **Wo?** | where (place) | Wo ist der Bahnhof? |
| **Wohin?** | where to | Wohin gehst du? |
| **Woher?** | where from | Woher kommst du? |
| **Wann?** | when | Wann beginnt der Kurs? |
| **Warum?** | why | Warum lernst du Deutsch? |
| **Wie?** | how | Wie geht es dir? |
| **Wie viel? / Wie viele?** | how much / how many | Wie viel kostet es? · Wie viele Leute? |
| **Welch-?** | which | Welches Buch ist das? |

## Numbers (the 10 you'll say daily)

null · eins · zwei · drei · vier · fünf · sechs · sieben · acht · neun · zehn

**+ teens/tens:** elf, zwölf, dreizehn… neunzehn, zwanzig, dreißig, vierzig, fünfzig, hundert, tausend.

**Backwards rule (21+):** 21 = ein**und**zwanzig, 47 = sieben**und**vierzig.

## Time & dates

| German | English |
|---|---|
| Wie spät ist es? | What time is it? |
| Es ist ein Uhr. / zwei Uhr. | It's 1 o'clock / 2 o'clock. |
| Es ist **halb fünf**. | It's half past four (4:30)! |
| Viertel nach / Viertel vor | quarter past / quarter to |
| Um wie viel Uhr? | At what time? |
| **Um** acht Uhr. | At 8 o'clock. |
| Heute / Morgen / Gestern | today / tomorrow / yesterday |
| Am Montag / am Wochenende | on Monday / at the weekend |
| Wann hast du Geburtstag? | When is your birthday? |

## The "möchte" formula (your most used phrase)

**Ich möchte + [ein/einen/eine] + noun, bitte.**
- Ich möchte **einen** Kaffee, bitte. (masc → einen)
- Ich möchte **ein** Wasser, bitte. (neut → ein)
- Ich möchte **eine** Cola, bitte. (fem → eine)
