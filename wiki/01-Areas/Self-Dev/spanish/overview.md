# Spanish via VideoEle — Overview & Roadmap

> **VideoEle = free video Spanish for foreigners** — no register, no pay. All materials CC BY-NC-ND 4.0. 4 levels: **A1 / A2 / B1 / B2** (CEFR). This vault hub mirrors the course structure so you can pick the right unit in 30 seconds.

## How VideoEle is organized (from `Curso.html`)

Each **Unidad didáctica** contains 5 things:

| Material | Format | What to do |
|---|---|---|
| **Vídeo** | 3-6 min YouTube, often with ES + EN/IT/DE subtitles (toggle in YouTube CC → Subtítulos) | Watch 1st without subs if easy, 2nd with subs to catch new words; hard videos → with subs first |
| **Transcripción** | PDF | After watching, read exact words, translate unknowns |
| **Guía didáctica** | PDF | 4 sections: **Antes de visionar** (prime topic) → **Mientras visionas** (answer during watch) → **Después de visionar** (most tasks) → **Para aprender más** (deep dive) |
| **Soluciones** | PDF | Check yourself; *Posible respuesta* = multiple correct |
| **Actividades interactivas** | H5P / e-book in browser | Do after video; replay video as needed |

**Where you fit:** VideoEle says it helps if you (a) want to maintain, (b) want complement to class, (c) start from zero, (d) self-study via TV/songs/internet — i.e., your current lecture + self-study case.

## Study loop (VideoEle-recommended + vault habit)

1. **Antes** → read Guía Antes, prime brain on topic
2. **Watch** (3-6 min) → without subs if easy, else with ES subs; pause/replay
3. **Mientras** → answer Guía questions during 2nd watch
4. **Después** → do Guía + interactives from memory, replay to fill gaps
5. **Transcripción** → read PDF, translate, shadow aloud (mimic voices)
6. **Soluciones** → check, learn from errors
7. **Anki** 5-10 words/day + 1 dialogue shadowing

Daily: 15-20 min = 1 unit every 1-2 days. Weekly: review 3 units, do 1 CancionEle song (https://videoele.com/CancionEle/index.html) for rhythm + listening.
