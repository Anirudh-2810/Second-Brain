# Spanish — Vocabulary & Phrases (A1 buckets)

| Bucket (VideoEle unit) | Core words / phrases |
|---|---|
| **En mi barrio hay** | la panadería, el supermercado, la farmacia, el parque, el banco, la biblioteca |
| **Tiendas** | la tienda de ropa, la zapatería, la frutería, ¿Cuánto cuesta? |
| **El cuerpo** | cabeza, cara, ojo, nariz, boca, mano, pierna, pelo |
| **¿Cómo son los gigantes?** | alto/bajo, guapo, moreno/rubio, gordo/delgado |
| **La comida** | pan, arroz, carne, pescado, fruta, verdura, leche, agua, café |
| **La familia del Rey** (+ family) | madre, padre, hijo/a, hermano/a, abuelo/a, primo/a, familia real |
| **Mi casa** | cocina, salón, dormitorio, baño, ventana, puerta, cama |
| **¿Qué llevan?** | camiseta, pantalón, vestido, zapatos, chaqueta |
| **Hacer deporte** | fútbol, baloncesto, tenis, nadar, correr + balón, raqueta |
| **Voy al instituto** | libro, cuaderno, bolígrafo, pizarra, mochila, clase |
| **Medios de transporte** | autobús, metro, tren, avión, coche, bicicleta — ir en / a |
| **Profesiones** | profesor, médico, ingeniero, cocinero, estudiante |
| **En el zoo** | león, elefante, jirafa, mono, tigre, oso |
| **¡Buen fin de semana!** | cine, fiesta, pasear, leer, a veces / siempre / nunca (frequency) |
| **Tiempo / hora** | hoy, mañana, ayer, lunes-domingo, enero-diciembre, Son las… |
| **Países / nacionalidades** | España-español, India-indio, México-mexicano, ¿De dónde eres? Soy de… |
| **Colores** | rojo, azul, verde, amarillo, negro, blanco — rojo/roja/rojos/rojas |

## Useful chunks

- **Frequency:** siempre, a menudo, a veces, nunca
- **Location:** aquí, allí, cerca, lejos, en mi barrio hay…
- **Shopping:** ¿Qué quieres? Quiero… / ¿Cuánto es?
- **Haber/Tener:** Hay tres tiendas. Tengo 19 años.
