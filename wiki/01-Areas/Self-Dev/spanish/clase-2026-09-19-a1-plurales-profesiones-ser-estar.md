## 1. Pronunciation top-ups (sounds the lecture drilled)

- **ch, ll, ñ** — the three Spanish-only sounds: *ch* as in *chico*, *ll* as in *llamo*, *ñ* as in *español*. Drill words from class: *estudiante, usar, universidad*.
- **ce, ci sound like 's'** — the teacher wrote "ce, ci, s-z: all these have sounds of 's'". That is Latin-American **seseo**: *c* before e/i = /s/ (so *ciudades, policía* start with an s-sound, not English k or Castilian th). Same for *z*.
- **y = "and"** — the letter/word *y* means "and" (*tú y yo*). Pronounced like "ee".
- **Double r rolls** — *terror* drilled for the trilled rr (tongue-tip roll, longer than single-r *pero*).
- **j = strong h** — *jugar* (to play), *jugo* (juice): j sounds like a throaty English h.
- **Word stress peek** — *tomate, diez, Dios, Días*: class read them aloud for vowel clarity (*ie* glides, accent marks signal stress). Full stress rules live in [[01-Areas/Self-Dev/spanish/alphabet-and-pronunciation|alphabet]].

## 2. Plurales — the complete rule set with lecture examples

| Rule | Pattern | Lecture examples |
|---|---|---|
| Vowel + **-s** | casa → casas | *ciudades* (ciudad is the exception below, but *española → españolas*, *bonita → bonitas*) |
| Consonant + **-es** | profesor → profesores | *autobús → autobuses, mes → meses* |
| **-z → -ces** | lápiz → lápices | ***lapiz → lapices*** (class spelling without accent: *lápiz → lápices*) |
| Days in **-s** stay same in singular/plural article change only | el lunes → los lunes | ***el lunes → los lunes*** |
| Words already plural-shaped | — | *los dientes* (the teeth — no singular change needed in class example) |
| Invariable agent nouns **-ante / -ista** | same form, article shows number | *el deportista → los deportistas; el deporte* (sport itself is masculine singular) |
| Nationality ending in vowel → **-s** | belga → belgas | *marroquí… belga* → *belgas* |
| Nationality stressed vowel + í → **-es** | marroquí → marroquíes | *marroquí → marroquíes* (class wrote "marroqui….") |

Headline sentence (agreement x3): ***las ciudades españolas son bonitas*** — feminine plural article + noun + nacionalidad adjective + verb + feminine plural adjective. Every word agrees.

## 3. Nacionalidades + agreement (from class sentences)

- *español / española / españoles / **españolas*** — the four forms; class used all positions: *el vino **español** es mejor que el vino italiano* (masc. sing.), *las ciudades **españolas** son bonitas* (fem. pl.).
- *marroquí → marroquíes; belga → belgas* — two more nationality patterns (consonant/í vs vowel ending).
- Comparison frame worth stealing: ***el vino español es mejor que el vino italiano*** — el + noun + nacionalidad + *es mejor que* + el + noun + nacionalidad. Reuse for any "X is better than Y".

## 5. Pronombres + SER (recap, same as 09-09 — one table)

| Singular | Plural |
|---|---|
| Yo (I) | Nosotros/nosotras (We) |
| Tú (you, informal) | Vosotros/vosotras (you all, informal Spain) |
| Usted (you, formal) | Ustedes (you all, formal) |
| Él / Ella (he/she) | Ellos / Ellas (they) |

No **it** in Spanish — *Es un libro* (It is a book), never *ello es* at A1.

**SER** (identity/essence): yo **soy**, tú **eres**, usted/él/ella **es**, nosotros **somos**, vosotros **sois**, ustedes/ellos **son**. Negation before the verb: *Yo no soy piloto. Ellos no son españoles.*

## 6. SER vs ESTAR — DOCTOR vs PLACE (the poster)

The lecture's poster settles every ser/estar doubt at A1:

**SER = DOCTOR** (what something IS — permanent/defining):

- **D**ate — *Hoy es lunes.*
- **O**ccupation — *Soy estudiante. Es médico.*
- **C**haracteristic — *Las ciudades son bonitas.*
- **T**ime — *Son las seis.*
- **O**rigin — *Soy indio/india. Es marroquí.*
- **R**elation — *Es mi compañero.*

**ESTAR = PLACE** (how/where something IS — state/position):

- **P**osition — *Estoy sentado.*
- **L**ocation — *Estás en casa.*
- **A**ction (present progressive) — *Estoy estudiando.*
- **C**ondition — *Está cerrado / enfermo.*
- **E**motion — *Están contentos.*

Conjugations side by side: SER *soy, eres, es, somos, sois, son* · ESTAR *estoy, estás, está, estamos, estáis, están*.

Test yourself: *El vino español ___ mejor* → SER (*es* — characteristic). *La tienda ___ cerrada* → ESTAR (*está* — condition). *___ las tres* → SER (*son* — time).
