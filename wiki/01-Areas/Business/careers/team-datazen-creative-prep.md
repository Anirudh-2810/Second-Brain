# Team DataZen Creative Prep

## 1. Design system (uniform, not decoration)

- **Grid = assembly lines.** Everything aligns to invisible lines, like school assembly. No floating elements.
- **Two fonts max.** Notice board in two languages max — headline font + body font, locked.
- **Palette locked.** House colours only (council colours), never random brights.
- **Whitespace = notebook margins.** No margin, teacher can't read. Breathing room is readability.
- **Hierarchy.** Headline big ("Hack Night Friday!"), details small, CTA last ("register link in bio").
- **Consistency = identity.** Same grid/fonts/colours across posts so followers recognize DataZen before reading.

Critique formula (when shown a poster): 1 strength + 1 fix + how. "Strong headline; I'd give the date more breathing room so it reads at thumbnail size."

## 2. Video pipeline (tiffin that opens tasty)

- **Hook 3s = aroma hit.** Hungry in 3 seconds or the tiffin shuts. First frame must earn the second.
- **Captions always.** Friend watches muted in class — story must survive silence.
- **Cut every 2–3s.** New bite, no boredom. Pace = retention.
- **Thumbnail = dabba sticker.** 3 words + face, or nobody picks it up.
- **CTA last.** "Link in bio," spoken and on screen.
- Tools, say by name: CapCut/Premiere — import → cuts → captions → basic color → export 1080p H.264. Canva/Figma — frames, text styles, components for repeated cards (event/recap/winner).

## 3. Metrics (report card, not one subject)

- Likes = attendance (showed up). Saves/shares = understood + teaches others (real marks).
- Retention graph = where kids slept in class — the dip timestamp is the edit fault; fix that cut.
- For council events: registrations, show-up rate, shares per post — the same show-up math as [[team-datazen-tech-prep]].

## 4. No-footage playbook (official line)

Bring: 2–3 raw phone clips + 2 thumbnails/posters (even class work) + one reference board of styles you like. Say: "No finished vlog yet — here's raw, here's how I'd cut it: 3s hook, captions burned, pace cut every 2–3s, thumbnail 3 words + face, 1080p export. Give me one past event — 48 hours, recap reel + thumbnail pack as trial." Process + offer beats archive. Never claim finished work that doesn't exist.

## 5. Content pipeline (repurpose one event)

One event → 1 recap reel + 3 posters (announce / reminder / winners) + 5 photos + feedback form → feedback CSV feeds the tech spoke's parser. This is the Tech×Creative multiplier story: compute the turnout, package it so the next turnout is bigger.

## 6. Grill answers (verbatim)

- **"Show work":** raw clips + posters, narrate hook/caption/pace per piece → trial offer.
- **"Our designs need work, no?":** "Strong base and consistent posting — I'd evolve: one grid, two fonts, council palette locked." Never trash.
- **Tool depth ("auto-layout? proxies?"):** real steps you know, then "haven't used proxies at scale — 10-minute tutorial + trial piece."
- **"Tech or creative, pick":** "Tech primary, Creative multiplier — the best analysis unseen is wasted; I package what I compute."
- **Process:** brief (goal + audience + deadline) → draft → review loop → template it so output speeds up.

## 7. Color + type basics (FY-proof)

- **Color roles:** background (quiet), primary (council color, CTAs + headlines), accent (sparingly — dates, arrows). 60-30-10 rule: 60% neutral, 30% primary, 10% accent.
- **Contrast = readability.** Grey-on-grey dies on phones in sunlight. Dark text on light, or white on deep color. Free check: squint test — headline must survive squinting.
- **Type roles:** one display font (headlines, personality) + one body font (details, legible small). Never three. Sizes: headline readable at thumbnail, details readable at arm's length.
- **Accessibility:** captions on every video (muted viewers + hearing-impaired), alt text on posters, no red-green-only meaning (color-blind members).

## 8. Platform specifics

- **Instagram Reel / YouTube Short:** 9:16 vertical, 1080×1920, hook in first 1–3s, captions burned in, 15–45s sweet spot, CTA spoken + on-screen end card.
- **Feed poster:** 1:1 or 4:5, headline ≤ 6 words, date-venue unmissable, council handle + logo lockup same corner every time.
- **Story:** 9:16, one idea per card, poll/sticker for interaction (also collects data — Tech angle).
- **Cadence story:** announce (2 weeks out) → reminder (2 days) → live stories (day) → recap reel + winners (48h) → feedback form. One event, five beats.

## 9. Copywriting (hooks + CTAs)

- **Hook formulas:** number ("3 reasons tonight fills fast"), question ("Free pizza + robots?"), stakes ("Only 40 seats").
- **Body:** one idea per post. Details in order: what → when/where → cost → link.
- **CTA:** single, imperative, last: "Register — link in bio." Never two links, never "link maybe in bio."
- **Tone:** DataZen = friendly-smart. No jargon without translation ("show-up rate = attendees ÷ registrations").
