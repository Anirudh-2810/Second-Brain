## What is n8n?

Open-source workflow automation tool (fair-code license). Connects 400+ apps via nodes. Workflows = triggers + logic + actions. Self-host free or use n8n Cloud. It is the engine behind every recipe in this module.

- Docs: https://docs.n8n.io
- Source library analyzed here: https://github.com/Zie619/n8n-workflows (MIT)
- Live search UI for that library: https://zie619.github.io/n8n-workflows

## Reading order for a complete beginner

1. `automations-catalog.md` — understand what exists (skim, 15 min)
2. `quick-start-guide.md` — install n8n, build first workflow today
3. `templates/starter-workflows.md` — import ready-made skeletons
4. Study the two core blueprints in `patterns/` — most client work is one of these
5. Pick your lane: `money/`, `company/`, or `daily/` (category recipes in `categories/`)
6. Come back to the catalog's pattern section when designing your own
