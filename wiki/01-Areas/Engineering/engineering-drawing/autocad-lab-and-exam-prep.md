> **DWG rule:** `.dwg` is a binary AutoCAD format — never open with the Read tool or a text editor. Catalog by name/size only. Practice tasks (TBC, standard Sem-1 set): `LINE`, `CIRCLE`, `ARC`, `RECTANGLE`, `POLYGON`, `TRIM`, `EXTEND`, `OFFSET`, `MIRROR`, `ARRAY`, `HATCH`, `DIMLINEAR`/`DIMSTYLE`, `LAYER`, `PLOT`/layout to A4.

### Lab sheet discipline (what rubrics usually reward)
- Correct layers (object / hidden / centre / hatch / dimension), BIS line types via linetype + lineweight.
- Title block filled (name, roll, date, scale, sheet no).
- Dimensions in mm, arrowheads closed-filled, text above line.
- Plot to scale on A4 with margins; keep a PDF export of every submission.

## 4. Sheet + exam-day checklists

**Every sheet:** [ ] A4, margins, title block filled · [ ] light construction first, darken last · [ ] hidden = dashed, centre = dash-dot · [ ] dimensions mm, Ø/R correct · [ ] section labelled + hatched 45° · [ ] first angle (top view below front).

**Exam day:** instruments (compass, set squares, scales, H/2H pencils), start with the view problem you know best, projectors across views before darkening, 10 min reserved for title block + error sweep (hidden lines, labels, traces stated).
