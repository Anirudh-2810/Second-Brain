# Unit 2A — Cell Biology & Central Dogma

## 1. Prokaryote vs eukaryote (exam table)

| | Prokaryote | Eukaryote |
|---|---|---|
| Nucleus | None (nucleoid) | Double-membrane envelope, gene regulation |
| Size/complexity | Small, no organelles | Compartmentalised (ER, Golgi, lysosomes, mitochondria) |
| Ribosomes | 70S | 80S (cytoplasmic) |
| Division | Binary fission | Mitosis/meiosis |
| Replication origins | Single ori | Multiple ori |

Organelle one-liners: rough ER (protein synthesis/folding) · smooth ER (lipids, detox) · Golgi (modify/package/ship — "post office") · lysosomes (enzyme recycling) · mitochondria (respiration → ATP; endosymbiotic origin ~1.5 Gya). Size logic: surface-area-to-volume ratio caps cell size; compartmentalisation beats the cap.

## 2. Cell cycle & mitosis

Interphase G1 (grow) → S (DNA duplicated) → G2 (prep) → M (mitosis). Checkpoints: G1 (DNA damage; **p53** "guardian" — mutated in >50% cancers), G2 (replication complete), M/spindle (chromosome attachment). Mitosis: prophase (condense, envelope breaks, spindle forms) → metaphase (equatorial plate) → anaphase (sister chromatids separate) → telophase + cytokinesis → two identical diploids (growth, repair, asexual reproduction).

## 3. DNA replication (enzymes in fork order)

Initiator proteins recognise **ori** → **helicase** unwinds (Y-fork) → **primase** lays RNA primer (polymerase needs 3′-OH) → **DNA pol III** elongates 5′→3′ (leading continuous; lagging as **Okazaki fragments** ~1000 nt prokaryote) → **pol I** swaps primers for DNA → **ligase** seals nicks. Proofreading 3′→5′ exonuclease keeps fidelity (anti-mutation/cancer logic).

## 4. Transcription (DNA→RNA)

Unit = promoter (upstream, polymerase binding) → start site → coding region → terminator. RNA polymerase synthesises 5′→3′ with U-for-T. Stages: initiation (bind promoter) → elongation → termination (release).

| | Replication | Transcription |
|---|---|---|
| Scope | Whole genome | Selected genes |
| Product | dsDNA (permanent) | ssRNA (temporary) |
| Template | Both strands | One strand |
| Frequency | Once/cycle | Repeated |
