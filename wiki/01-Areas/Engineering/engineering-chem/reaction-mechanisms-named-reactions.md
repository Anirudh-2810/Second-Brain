# Named Reactions — Mechanism Deck

## 1. C–C bond formation at carbonyls

- **Aldol condensation**: two carbonyls with $\alpha$-H + base/acid → $\beta$-hydroxy carbonyl (aldol) → dehydration to $\alpha$,$\beta$-unsaturated carbonyl. Key intermediate: **enolate ion**. New C–C bond formed.
- **Claisen–Schmidt condensation**: crossed aldol between an aromatic aldehyde (no $\alpha$-H, e.g. benzaldehyde) and a ketone (acetophenone) under base → **benzalacetophenone (chalcone)**. This is Chem Lab Expt 5 per the write-up index; no procedure file was supplied, so only the transformation is examinable from sources.
- **Wurtz synthesis**: $2\,\mathrm{R\!-\!X} + 2\,\mathrm{Na} \xrightarrow{\text{dry ether}} \mathrm{R\!-\!R} + 2\,\mathrm{NaX}$. Couples alkyl halides to (usually symmetric) higher alkanes. Variant **Wurtz–Fittig**: alkyl halide + aryl halide → substituted aromatic.

## 2. Carbonyl oxidation / rearrangement set

- **Haloform**: methyl ketone $+\ \mathrm{X_2/NaOH} \to \mathrm{CHX_3} + \mathrm{RCOO^-}$. Diagnostic for $\mathrm{CH_3CO}-$ group; products are haloform + carboxylate salt.
- **Baeyer–Villiger oxidation**: ketone + peroxyacid → ester (cyclic ketone → lactone). One O atom inserts beside the carbonyl; migratory aptitude: tertiary > secondary > phenyl > primary > methyl. Pharma/flavour synthesis use.
- **Dakin reaction**: o-/p-hydroxy phenyl aldehyde or ketone $+\ \mathrm{H_2O_2}$/base → benzenediol + carboxylate (nucleophilic addition → aryl migration → ester hydrolysis). Converts carbonyl carbon into phenolic –OH.
- **Benzil–benzilic acid rearrangement**: 1,2-diketone (benzil) + strong base (KOH) → $\alpha$-hydroxy acid salt. Steps: $\mathrm{OH^-}$ attack on one C=O → 1,2-aryl migration → proton transfer.
- **Pinacol–pinacolone**: 1,2-diol (pinacol) under acid → ketone. Steps: –OH protonation → $\mathrm{H_2O}$ loss → carbocation → 1,2-alkyl shift → deprotonation.
- **Fries rearrangement**: aryl ester $+\ \mathrm{AlCl_3}$ (Lewis acid) → o-/p-hydroxy aryl ketone via acyl migration. Low T favours para, high T favours ortho.

## 3. Stereoselective oxidation

- **Sharpless epoxidation**: allylic alcohol + t-BuOOH, catalysed by $\mathrm{Ti(OiPr)_4}$ + diethyl tartrate → 2,3-epoxy alcohol with **enantioselectivity**. The tartrate ligand sets the face of oxygen delivery.

## 4. Exam heuristics

- See $\mathrm{CH_3CO}-$ + $\mathrm{X_2}$/base → think **haloform**.
- See ketone + peroxyacid → think **Baeyer–Villiger**, migrate the more substituted group.
- See 1,2-diol + acid → think **pinacol**, shift to the more stable carbocation.
- See aryl ester + $\mathrm{AlCl_3}$ → think **Fries** (temperature controls o/p).
