# 2026-10-17

## Log

- **HandwriteAI — landscape pagination shipped**: the renderers used to emit one tall vertical strip (`width=1600`, height auto-grown per wrapped line); the owner wanted horizontal sheets. All three renderers in `HandwriteAI/inference.py` (`render_text_image`, `render_with_glyphs`, `render_labeled`) now default to **`width=3500, page_h=1800`**, split wrapped lines at `(page_h-140)//line_h` lines per page (10 for labeled/buckets, 13 for font), and return `List[Image]`; `page_h=None` keeps the old strip.
- **Hard constraint honoured**: letterforms/ink unchanged — the draw loop is byte-identical, only the canvas swaps at page boundaries. Glyph size, jitter, welds, word gaps, seeds all untouched.
- **Export** (`export_outputs`) → `{format: [paths]}`: one PNG/SVG per page (`-p1`… when multi), one multi-page PDF (reportlab `showPage()`; PIL `append_images` fallback).
- **Wiring**: `convert.py` (`--width 3500 --page-h 1800`, `--page-h 0` = strip), `gradio_ui.py` (preview page 1, download all pages); helper scripts `_pdf1_render`/`_scan_render`/`_prune_e_open` pass `page_h=None`+`[0]`, diagnostics `_ggate`/`_proof`/`_render_align`/`_verify` updated with `[0]`.
- **Verified**: labeled short → 1 page; 6-para → 3 pages × 3500×1800; `page_h=None` → 3500×3728 strip; font → 3500×1800; buckets → 2 pages; export → 3 PNGs + 1 three-page PDF (pypdf); CLI + Gradio handlers end-to-end.
