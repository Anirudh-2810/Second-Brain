# Patterns

Recurring patterns across sessions. When a new task resembles one of these, follow it.

## How the User Works

- **Core ideas only.** Repeatedly strips systems to essentials ("too cluttered", "take only the core ideas"). Propose lean defaults; every file must earn its place.
- **Capture → distill pipeline.** Nothing is read from raw form twice: immutable originals in `raw-sources/`, distilled linked notes in `wiki/modules/`. When given external content (books, papers, chats), distill — never dump.
- **Graph-first organization.** Wikilinks over folders; indexes ([[wiki/index]], [[Memories]]) actively curated.
- **Visual habit dashboards.** Daily tracking via frontmatter fields (`Study`, `Exercise`, `Mood`, `Vlogging`, `Guitar`) rendered as heatmaps and live signals on [[Home]].
- **Agent-maintained everything.** Comfortable letting agents restructure the vault wholesale, as long as existing content is preserved and moves are explained.

## Session Rhythm

- Big restructuring bursts in single sessions, then refinement passes
- Uses slash commands as entry points rather than ad-hoc prompts
- Exports AI conversations worth keeping (Gemini shares) into the vault
