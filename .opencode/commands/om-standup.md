---

Run the morning standup.

1. Read `brain/North Star.md` — ground everything in current goals
2. Read yesterday's and today's daily notes if they exist (`daily/YYYY-MM-DD.md`)
3. Check the last few entries in `wiki/log.md` and `bases/Recently Touched.base` data for what's in flight
4. Scan `daily/index.md` for gaps (missed days)

Present a structured standup:
- **Yesterday**: What got done (from daily note + wiki log)
- **Streaks**: Study hours, exercise, mood trends from recent daily notes
- **Open Loops**: unfinished tasks or dangling follow-ups from recent notes
- **North Star Alignment**: how current work maps to goals
- **Suggested Focus**: 1–3 priorities for today, tied to North Star

Keep it concise — orientation, not a deep dive.
